# Feature SC-20: Extended Soroban Contract Event Emission & SDK Capability

## Overview
SC-20 extends Soroban smart contract event emission and provides client capabilities within the SDK for listening to and verifying custom contract event streams.

## Features
- **Contract Event Emission:** Emits structured event topics for state mutations and draw actions.
- **SDK Event Parser:** Decodes and parses raw RPC event logs into typed structures.
- **Verification Helper:** Off-chain validator utility for contract events.

## Usage
```typescript
import { parseSC20Event } from "@soroscan/sdk";

const event = parseSC20Event({ contractId: "C123", topic: "draw", data: { winner: "G123" } });
```
