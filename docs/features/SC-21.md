# Feature SC-21: Extended Soroban Event emission & SDK Filter Helpers

## Overview
SC-21 adds custom event filtering and structured topic payloads for Soroban smart contracts and client SDKs.

## Features
- **Contract Event Emission:** SC-21 structured topic and vector payload helper.
- **SDK Event Filter:** Off-chain helper for filtering event feeds by topics and contract IDs.

## Usage
```typescript
import { filterSC21Events } from "@soroscan/sdk";

const filtered = filterSC21Events(events, "SC21");
```
